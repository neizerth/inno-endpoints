## Prisma vs Raw SQL

| Raw SQL | Prisma |

| Строковые запросы | Типизированные методы |
| Ручной маппинг | Автогенерация типов |

## Схема: Product

```prisma
model Product {
  id          Int      @id @default(autoincrement())
  name        String
  slug        String   @unique
  description String?
  price       Decimal  @db.Decimal(10, 2)
  stock       Int      @default(0)
  isActive    Boolean  @default(true)
  categoryId  Int
  category    Category @relation(fields: [categoryId], 
                                 references: [id])
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@index([categoryId])
  @@index([isActive])
}
```

## Атрибуты полей

| Атрибут | Назначение |
|---------|------------|
| `@id` | Первичный ключ |
| `@default(autoincrement())` | Автоинкремент |
| `@unique` | Уникальное ограничение |
| `@relation` | Внешний ключ |
| `@db.Decimal(10, 2)` | Тип в PostgreSQL |
| `@@index` | Индекс таблицы |

## Prisma Client — singleton

**src/lib/prisma.ts**
```typescript
import { Pool } from 'pg';
import { PrismaPg } from '@prisma/adapter-pg';
import { PrismaClient } from '@prisma/client';

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClient | undefined;
};

function createPrismaClient(): PrismaClient {
  const pool = new Pool({ 
    connectionString: process.env.DATABASE_URL 
  });
  const adapter = new PrismaPg(pool);
  return new PrismaClient({ adapter });
}

export const prisma = globalForPrisma.prisma ?? createPrismaClient();

if (process.env.NODE_ENV !== 'production') {
  globalForPrisma.prisma = prisma;
}
```

---

## Зачем singleton?

**Проблема:** при hot-reload создаются новые подключения

**Решение:** сохраняем клиент в globalThis

```typescript
// Первый импорт — создаём клиент
const prisma = createPrismaClient();
globalForPrisma.prisma = prisma;

// Последующие импорты — используем существующий
const prisma = globalForPrisma.prisma;
```

  if (categoryId) where.categoryId = Number(categoryId);

});

# CORS

---

## Проблема Same-Origin Policy

Браузер блокирует запросы между разными origin:

```
Frontend: http://localhost:5173
Backend:  http://localhost:3000
```

**Origin** = протокол + домен + порт

Запрос с frontend на backend — кросс-доменный, браузер его блокирует

---

## Что такое CORS

**Cross-Origin Resource Sharing** — механизм, позволяющий серверу
указать, каким origin разрешено обращаться к API

Сервер отвечает заголовками:
```
Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, PUT, DELETE
Access-Control-Allow-Headers: Content-Type, Authorization
```

---

## Preflight запросы

Для "сложных" запросов браузер сначала отправляет **OPTIONS**:

```
1. Browser → OPTIONS /api/products
2. Server  → 200 OK + CORS headers
3. Browser → POST /api/products (если разрешено)
```

Сложные запросы: PUT, DELETE, с кастомными заголовками

---

## Подключение cors

```bash
npm install cors
npm install -D @types/cors
```

```typescript
import cors from 'cors';

const app = express();

app.use(cors());  // Разрешить все origin
app.use(express.json());
```

---

## Конфигурация cors

```typescript
app.use(cors({
  origin: 'http://localhost:5173',  // Конкретный origin
  methods: ['GET', 'POST', 'PUT', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization'],
  credentials: true,  // Разрешить cookies
}));
```

---

## Несколько origin

```typescript
const allowedOrigins = [
  'http://localhost:5173',
  'http://localhost:3001',
  'https://myapp.com',
];

app.use(cors({
  origin: (origin, callback) => {
    if (!origin || allowedOrigins.includes(origin)) {
      callback(null, true);
    } else {
      callback(new Error('Not allowed by CORS'));
    }
  },
}));
```

---

## CORS в production

```typescript
const corsOptions = {
  origin: process.env.NODE_ENV === 'production'
    ? 'https://myapp.com'
    : '*',
  credentials: true,
};

app.use(cors(corsOptions));
```

Ограничивайте origin в production для безопасности

# Авторизация

---

## Passport.js

Middleware для аутентификации:
- Модульная архитектура
- 500+ стратегий
- Простая интеграция с Express

---

## Basic Authentication

```
Authorization: Basic YWRtaW46YWRtaW4xMjM=
                     └── base64(admin:admin123)
```

- Credentials в каждом запросе
- Требует HTTPS в production

---

## Настройка стратегии

**src/lib/auth.ts**
```typescript
import passport from 'passport';
import { BasicStrategy } from 'passport-http';
import { prisma } from './prisma.js';

passport.use(
  new BasicStrategy(async (username, password, done) => {
    try {
      const user = await prisma.user.findUnique({
        where: { username },
      });

      if (!user || user.password !== password) {
        return done(null, false);
      }

      return done(null, user);
    } catch (error) {
      return done(error);
    }
  })
);
```

---

## Middleware аутентификации

```typescript
export const authenticate = passport.authenticate(
  'basic', 
  { session: false }
);

export default passport;
```

**session: false** — stateless, проверяем credentials каждый запрос
